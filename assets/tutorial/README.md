# 제공된 V3 에셋

사용자가 제공한 `hook_recoil_tutorial_v3`의 PNG 6개와 `atlas.json`을 복사했다. 원본 안내는 [보관한 README](../../docs/assets/TUTORIAL_V3_README.md)에 있다. Downloads 원본을 수정하지 않는다.

- `atlas.json`: 각 이미지의 명시적 top-left rect, 애니메이션 분류.
- `assets/background.png`: 비반복 동굴 배경.
- `assets/player_movement.png`: 이동·점프·착지.
- `assets/player_actions.png`: 갈고리·스윙·반동·사망. 뒤쪽 발사는 런타임 UV 좌우반전.
- `assets/terrain.png`: 천장 구조물 등 지형 조각.
- `assets/tiles.png`: 바닥·절벽 타일.
- `assets/objects.png`: 링·줄·갈고리·총·체크포인트·출구·이펙트.

PNG 색상 키 제거·재인코딩·리샘플링 없음. 소유/사용 허가는 사용자 제공 자료 기준이며 별도 상용 배포 라이선스는 이 문서에서 확정하지 않는다.
