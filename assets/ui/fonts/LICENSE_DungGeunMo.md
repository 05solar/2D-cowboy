# 둥근모꼴+ Fixedsys 글꼴 라이선스

- 글꼴: 둥근모꼴+ Fixedsys (`DungGeunMo`)
- 제작자: 길형진 (orioncactus)
- 출처: Noonnu 웹폰트 배포 주소 (아래 원본 URL)
- 프로젝트에 포함한 TTF 변환본: `DungGeunMo.ttf` (원본 WOFF 글리프 데이터 유지)
- 생성한 비트맵 글꼴: `prologue.fnt`, `prologue.png`

제공된 라이선스 본문 안내에 따라 원본과 동일한 퍼블릭 도메인 조건으로 재배포·수정·상업적 사용이 가능하다. 이 프로젝트는 제공된 해당 본문 조건을 기준으로 글꼴 원본과 생성 글리프를 포함한다.

원본 웹폰트 주소: https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_six@1.2/DungGeunMo.woff
