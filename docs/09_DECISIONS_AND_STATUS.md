# 결정 및 현재 프로젝트 상태

기준일: 2026-11-05. 실행 가능 범위와 검증 결과를 요약한다. 작업 재개 절차와 미완료 항목은 [PROJECT_HANDOFF.md](PROJECT_HANDOFF.md), 문서 탐색은 [README.md](README.md)를 기준으로 한다. 계획 수치나 `available=true`는 완주·난도 검증을 뜻하지 않는다.

## 현재 상태

- 엔진은 기존 Java/libGDX `core`·`lwjgl3`; 게임 규칙 코드는 `io.github.hookrecoil`, LWJGL launcher는 기존 `io.github.some_example_name.lwjgl3` 패키지다.
- 별도 프롤로그와 본편 동굴 1~5, 광산 6~10, 지하도시 11~15 맵 데이터가 있다. 본편 16~20은 catalog metadata만 있어 시작할 수 없다.
- 1~15는 테스트 요청에 따라 실행 가능 상태로 두었다. 실제 해금 기록은 ID 기반 진행 저장과 별도다.
- 시작 카메라는 스폰에서 전체 맵을 축소해 보여주고 보석 위치로 확대했다가 스폰으로 돌아온다.
- 클리어는 바닥에서 보석 접촉으로 확정한다. 획득 중 물리/입력은 정지하고 별도 2초 연출 후 결과로 간다. 기록 시간은 접촉 시점으로 고정한다.
- 사망 화면은 자동으로 재시작하지 않고 YOU DIED 패널에서 입력을 기다린다.
- 본편 캐릭터 그림 배율은 0.68, 프롤로그는 0.75다. 충돌체 크기는 변경하지 않았다.
- 광산 6~10 발판 배치는 세 종류 실루엣을 섞고 위험 데이터 수를 1/3/6/8/10으로 늘렸다. 상세는 [광산 상태](MINE_CHAPTER_STATUS.md).
- Windows 창 아이콘은 저장소의 PNG/ICO 설정을 사용한다. 작업표시줄 재실행 아이콘은 과거 native 설정 실패가 있어 해결로 간주하지 않는다.

## 주요 결정

| 날짜 | 결정 |
|---|---|
| 초기 프로젝트 | 원본 명세는 보존하고 후속 구현 차이는 별도 문서에 기록한다. 기능별 Java 파일과 한국어 상단 역할 주석을 사용한다. |
| 프롤로그 조정 | 천장 구조물에 지지된 링만 갈고리에 연결한다. 긴 천장 없는 틈은 반동이 필요한 점프로 건넌다. 뒤쪽 사격 포즈는 좌우반전한다. |
| 보석 클리어 | 기존 출구 대신 `clear_gem` 접촉을 사용한다. 공중 접촉은 획득하지 않으며 바닥 접촉만 확정한다. 같은 틱 사망 우선. |
| 저장 | 고정 stage ID를 사용하고 진행 schema 2에 완료·기록·수집품·pending journal을 저장한다. 스테이지 선택 포커스는 진행 데이터가 아니다. |
| 카메라 | 플레이 시작 때 전체 맵을 투어하되 월드 조작은 정지하고 16:9 게임 시야를 유지한다. |
| 테스트 가용성 | 구현된 1~15 맵은 직접 점검할 수 있도록 열고, 미구현 16~20은 잠근다. 가용성과 검증 완료를 분리한다. |

## 남은 주요 검증

- 광산 각 체크포인트에서 실제 갈고리·반동 조작으로 시작하는 경로와 사망 원인을 수동 확인한다.
- 지하도시 11~15 전체 경로, 특히 city_05 이동 장치 문제를 직접 확인한다.
- 전체 1~15의 수동 클리어·난도 상승·가시 가독성, CP 위상 초기화 반복, 최대속도 이동체/함정 관통 및 30/60/144FPS 일관성을 확인한다.
- 1080p 성능, 최소/권장 하드웨어, 배포 패키지와 깨끗한 환경 실행을 확정한다.
- 본편 캐릭터 축소는 렌더 배율만 변경했다. 맵 전역에서 가독성을 수동 확인한다.

- 2026-11-04: 본편 캐릭터 시각 배율 `0.68`을 추가했다. 물리 충돌체는 그대로 둔다.
- 2026-11-04: 광산 6~10의 발판 폭 일괄 보정을 없애고 지형 배치와 위험 수 1/3/6/8/10을 차별화했다. 표면 검사 31 assertions 및 native 로드 19 checks 통과. 자동 경로 진단 실패는 미해결로 기록한다.
- 2026-11-05: 상위 개발 문서·저장/맵 설명·인수인계를 현재 코드에 맞춰 정리한다. 원본 명세와 제공 에셋의 참조 문서는 보존한다.
