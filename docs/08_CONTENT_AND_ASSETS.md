# 콘텐츠·에셋 제작 계획

테마별 순수 주행 목표/발판 폭: 동굴 45~90초/2~3H, 광산 60~120초/1.5~2H, 도시 90~150초/1~1.5H, 지상 90~180초/0.8~1.2H. 모두 초기 설계 예산이며 검증된 플레이타임은 아니다.

## 맵별 문서 양식

제작 시 `docs/stages/stage_XX.md`에 학습 목표, 3개 이상 구간, 시작·CP·출구, 기본/선택 경로, 구간별 연결→해제→발사→착지 순서와 탄약, 안전 관찰 지점, 실패 복구, 카메라, 함정 예고·위상, 수집품, 도형맵 검증 결과를 적는다. 좌표 수치는 맵 데이터를 기준으로 하고 문서에는 의도와 검증을 남긴다.

정지·2발에서 각 구간이 성립해야 한다. 기본 경로는 0.15초 미만 단발 타이밍 창을 요구하지 않는 것을 초기 기준으로 삼는다. 종합 시험에 새 장치를 넣지 않는다. 마지막 출구는 넓고 안전하며 조작으로 마지막 걸음을 옮긴 후 엔딩으로 이어진다.

초기 계획에서는 화풍·캐릭터 디자인·픽셀 밀도·프레임 수·음원 포맷을 미정으로 두었다. 이후 사용자가 제공한 V3 에셋의 카우보이형 캐릭터와 동굴 배경을 테스트 프롤로그에 적용했다. 정식 스토리 설정 변경이나 전체 테마 스타일 확정과는 구분한다. 상세는 [프롤로그 문서](10_PROLOGUE.md)를 따른다.

실제 충돌체와 시각 장식은 분리한다. 고정점은 장식 케이블과 구분하고, 어둠이나 밝은 하늘에서도 윤곽을 유지한다. 에셋마다 원본 경로·제작자/출처·사용 허가·편집 파일·배포 파일을 인접 Markdown에 기록한다. 테스트용 로고는 실제 배포 전에 교체한다.
