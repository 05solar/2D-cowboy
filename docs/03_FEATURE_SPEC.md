# 기능 사양과 구현 상태

기준일: 2026-11-09. 게임 기획 원문은 [원본 명세](specs/HOOK_RECOIL_Game_Spec_v1.md)다. 이 문서는 플레이 가능한 프로토타입의 현재 동작을 요약한다. 목표 수치가 코드에 있거나 자동 검사에 통과해도 전 맵 밸런스가 확정된 것은 아니다.

## 플레이어 입력

| 입력 | 현재 동작 |
|---|---|
| A/D, 좌우 방향키 | 지상·공중 이동 및 스윙 중 방향 제어 |
| Space | 지상 점프 |
| 마우스 | 조준. 화면 좌표를 월드로 역변환 |
| 왼쪽 클릭 | 누를 때 반동탄 1발 발사. 누르고 있는 동안 연속 발사하지 않음 |
| 오른쪽 버튼 | 누르는 동안 갈고리 발사/연결 시도, 해제 시 줄 해제 |
| R | 일반 플레이에서는 활성 체크포인트 재시작. YOU DIED/결과 화면에서는 재도전 동작 |
| M | 스테이지 선택 열기 |
| Esc | 일시정지 또는 닫기/복귀 |
| F1 | 디버그 상태 표시 |

원본 명세의 모든 입력 재설정·키 재매핑·설정 화면이 완성됐다는 뜻은 아니다. 정확한 물리값은 `assets/config/physics.json`과 [기술 사양](02_TECHNICAL_SPEC.md)에 둔다.

## 갈고리·반동·착지

갈고리는 유효한 링/고정점에 시야가 열려 있을 때 연결한다. 원본 설정의 최대 사거리 7H, 발사체 40H/s, 적중 반경 0.28H가 적용된다. 프롤로그의 천장 없는 긴 틈은 기본 점프만으로 건너도록 설계하지 않고, 점프와 반동 발사를 사용한다. 총 발사 포즈는 진행 방향에 맞춰 좌우 반전한다.

기본 반동 크기는 5.5H/s, 탄창은 2발이다. 정상 착지와 데이터에 있는 재충전 링이 탄약을 회복시킨다. 각 맵에서 탄약 순서와 통과 난도가 수동 검증됐다고 보지는 않는다. 프롤로그 전용 스윙 가속과 줄 수축 조정은 [프롤로그](10_PROLOGUE.md)에 정리한다.

## 위험·죽음·재시작

치명 위험이나 낙사 시 사망한다. 같은 물리 틱에 클리어 보석과 위험 접촉이 겹치면 사망을 먼저 처리한다. 사망 후 0.35초 포즈가 끝나도 자동 복귀하지 않고 `YOU DIED`와 조작 설명을 유지한다. 사용자가 R 재시작 또는 메뉴 동작을 입력해야 진행한다. 체크포인트 활성화 안내 팝업은 없다.

장치의 타이머·충돌 상태·이동체 위상은 스테이지별 런타임 소유자가 초기화한다. 재시작 횟수 100회, 모든 장치 조합과 최대속도 충돌이 검증 완료된 상태는 아니다.

## 완료·진행

출구 도달 대신 바닥 `clear_gem` 접촉이 완료 조건이다. 획득 시간은 접촉 틱에 고정한다. 획득 뒤 `COLLECTING`에서 입력·이동·중력·갈고리·함정 시뮬레이션을 정지하고 별도 2초 연출을 진행한다. 종료 화면 제목은 `CLEAR`이며 다음 진행 해금과 결과 저장을 한 번 처리한다. 선택 수집품은 별도 ID다. 저장 구현은 [05_DATA_AND_SAVE_SPEC.md](05_DATA_AND_SAVE_SPEC.md)와 [11_GEM_CLEAR.md](11_GEM_CLEAR.md)를 따른다.

## 화면·콘텐츠 범위

- 스테이지 시작 카메라: 스폰에서 시작해 전체 맵을 보여주고, 보석을 비춘 뒤 스폰으로 돌아온다. 연출 중 물리는 정지한다.
- 기본 창 1600×900. 플레이 영역 16:9. 더 큰 창은 월드 시야를 넓히며 아트 자체를 키우지 않는다.
- 스테이지 선택은 카탈로그 길이에 따라 카드를 만들고, 진행 저장의 잠금과 실행 가용성을 분리한다.
- 실행 맵: 프롤로그 및 본편 1~15. 본편 16~20은 맵이 없어 시작할 수 없다.

## 범위 밖 또는 미확정

전체 20개 캠페인, 타이틀·설정·엔딩의 완성, 키 재매핑, 모든 수집품·기록 모드, 사람 대상 난도 평가, 전 맵 수동 클리어, 성능 기준·배포 패키지는 완료로 선언하지 않는다. 최신 항목별 상태는 [09_DECISIONS_AND_STATUS.md](09_DECISIONS_AND_STATUS.md)를 본다.
