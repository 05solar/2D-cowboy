# 기능 사양

기획 기준은 [원본](specs/HOOK_RECOIL_Game_Spec_v1.md)이다. 아래 수치는 확정 밸런스가 아닌 초기값이다.

2026-10-26 사용자 추가 요구: 프롤로그 갈고리는 실제 천장 구조물에 붙은 링에만 연결한다. 천장 없는 긴 구멍은 기본 점프보다 멀리 가는 반동 점프로 통과한다. 오른쪽 진행을 위한 뒤쪽 발사 모션은 제공 시트의 좌우반전이다. 실제 적용 범위는 [프롤로그](10_PROLOGUE.md)를 따른다.

후속 플레이 피드백에 따라 프롤로그는 접선 스윙 가속과 점진적 줄 당김을 적용한다. 아래 원본 기반의 고정 길이 규칙과 구분하며 최신 프롤로그 수치는 위 링크의 조정 항목을 우선한다.

## 입력·이동 (원본 4, 5.1절)

| 행동 | 기본 입력 | 계약 |
|---|---|---|
| 이동 | A/D | 지상 최고 4.5H/s. 공중 가속 5H/s², 수평 ±4.5H/s 안에서만 입력 가속. 기존 고속을 강제로 낮추지 않음 |
| 점프 | Space | 위쪽 8H/s, 지상 1회, 코요테 0.08초, 입력 버퍼 0.10초. 이단/벽 점프 없음 |
| 조준 | 마우스 | 월드 좌표로 변환해 갈고리와 총이 공유 |
| 반동 | 왼쪽 클릭 | press 1회에 1발, 유지 자동 발사 없음 |
| 갈고리 | 오른쪽 클릭 | press 발사, hold 유지, release 해제. 설정에서 토글 제공 |
| 재시작 | R | 마지막 체크포인트 복원. 스테이지 처음부터는 메뉴의 별도 명령 |
| 일시정지 | Esc | 재개·설정·스테이지 선택·타이틀 |

중력 24H/s², 전체 속력 상한 16H/s. 바닥 접촉 유지 0.05초를 유효 착지로 판정한다. 점프 가능 접촉과 탄약 회복용 유효 착지 시간을 분리해 즉각적인 점프를 불필요하게 지연시키지 않는다(설계안). 지상 가속·감속, 충돌체 폭, 바닥 법선 임계값은 P1 튜닝 항목이다.

키 변경은 행동 단위 매핑으로 저장한다. 중복 키 충돌을 알리고 기본값 복원을 제공한다(설계안). 사망·복원·메뉴 복귀·포커스 복귀 시 이전 입력을 비우고 버튼 release 이후의 새 press만 받는다. 조준 벡터 길이가 0이면 마지막 유효 방향을 사용한다(설계안).

## 갈고리 (원본 5.2절)

- 상태: `IDLE → FLYING → ATTACHED → IDLE`. 실패·해제·사망·차단도 IDLE로 복귀한다.
- 사거리 7H, 발사체 40H/s, 재발사 간격 0.15초. 한 번에 하나만 존재한다.
- 시야가 열린 링에 실제 적중해야 연결한다. 일반 벽 연결·벽 관통·자동 끌어올림·줄 감기·길이 조절은 없다.
- 연결 순간 거리를 줄 최대 길이로 저장한다. 그 안에서는 느슨하고, 밖으로 나가는 움직임만 제한한다.
- 줄이 팽팽할 때 고정점 대비 바깥쪽 상대 속도를 제거하되 접선 성분을 유지한다. 이동 고정점의 속도를 반영한다.
- 반동 발사 후에도 같은 줄 제약을 적용한다. 해제 시 현재 속도를 유지하며 추가 추진을 주지 않는다.
- 발사 중에도 스윕/선분 검사로 장애물을 확인한다. 연결 줄의 차단은 즉시 해제한다. 적중 허용 반경은 `assets/config/physics.json`의 `hookHitRadius`(0.28H)를 사용하며 조준 유효 표시와 실제 적중에 동일하게 적용한다. 차단 근접 예고 거리는 P1에서 시각 범위 안으로 정한다.
- 토글 모드는 첫 press 발사·유지, 다음 press 해제. 실패 후 자동 재발사하지 않는다(설계안).

## 반동·재충전 (원본 5.3절)

`velocity += -normalize(aim) × 5.5H/s`, 성공 발사 간격 0.22초, 탄창 2발. 발사 가능 시에만 탄약을 1 줄인다. 0발은 소리·HUD만 반응하고 속도는 변하지 않는다.

유효 착지 시 2발, 공중 재충전 링 통과 시 2발. 벽 스침·갈고리 연결/해제는 충전하지 않는다. 링은 해당 시도에서 1회만 사용하며 사망·체크포인트 재시작 시 사용 상태를 초기화한다. 이미 바닥에 있을 때 발사 직후 매 틱 충전되는 일을 막기 위해 착지 이벤트와 재이륙 상태를 관리한다(설계안, P1 검증).

## 환경 장치 (원본 8~9절)

| 장치 | 기능·초기화 계약 |
|---|---|
| 가시·회전 톱 | 위험 범위 접촉 시 사망, 보이는 위험보다 큰 판정 금지 |
| 붕괴 발판 | 착지 후 약 1초 뒤 붕괴, 균열·음향 예고, 리셋 시 복원 |
| 압착기 | 고정 주기·예고·위험 상태, 끼임을 관통으로 해결하지 않음 |
| 전기 장벽 | 주기 활성화 시 치명적이며 줄·갈고리 발사체도 차단, 전환 예고 |
| 이동 발판·광차 | 고정 경로·주기·위상, 정상 착지 충전, 이탈 속도 전달 1회 |
| 이동 고정점 | 고정된 범위 왕복, 상대 속도로 제약 계산 |
| 기류 | 구역별 일정 방향·가속, 경계·방향 표시, 임의 풍량 변경 없음 |

일방통행 발판은 위에서 하강할 때만 받치는 방식으로 설계한다. 갈고리/줄 차단 여부를 충돌 마스크로 별도 명시하고 테스트한다. 세부 충돌 규칙은 P1에서 확정한다.

## 상태·진행 (원본 3, 6, 11~13절)

`TITLE → PLAYING ↔ PAUSED`, `PLAYING → DEAD → RESTARTING → PLAYING`, `PLAYING → CLEARED → 다음 스테이지/선택`, 20번 최종 출구에서 `ENDING`으로 이동한다. 화면 선택과 게임 상태는 구분한다.

- HP·낙하 피해 없음. 치명물·맵 밖 추락만 사망, 일반 벽 접촉은 침투 방향 속도만 제거한다.
- 기본 모드는 시간·목숨 제한 없음. 살아서 출구 진입 시 클리어, 다음 스테이지 해금. 같은 틱 사망이 우선한다.
- 재시작은 위치·속도 0·탄약 2·줄 없음·링 미사용·장치 기준 위상으로 복원한다. 시도 시간과 사망 수는 유지한다.
- R 수동 재시작은 사망 수를 늘리지 않고 별도 진단 횟수로 센다(설계안). 스테이지 처음부터는 새 시도다.
- 체크포인트 저장과 이어하기는 임의 공중 위치가 아닌 안전한 체크포인트 기준이다.
- 수집품은 맵별 1개. 임시 획득 후 사망 시 취소, 생존 체크포인트/출구 도달 시 영구 확정. 해금 조건에는 사용하지 않는다.
- 일반·노체크포인트·기록 도전은 모드별 기록 분리. 연습 기록은 공식 기록에서 제외한다. 후순위 모드 UI는 일반 20개 검증 뒤 구현한다.

## 카메라·UI·오디오 (원본 10, 14절)

카메라는 경계·데드존·이동 방향 선행 추적을 적용한다. 자동 줌은 없다. 리사이즈 후에도 입력 좌표를 뷰포트로 역변환하고 여백 클릭은 월드 발사로 처리하지 않는다(설계안).

필수 화면: 타이틀, 이어하기/새 게임, 4테마 20스테이지 선택, HUD(탄약·스테이지·체크포인트·선택 타이머/사망 수), 일시정지, 설정, 결과, 시작/엔딩. 결과에는 시간·사망·수집·개인 최고·다음/재도전을 표시한다.

설정: 키 변경, 갈고리 누르기/토글, 음량, 화면 모드, 화면 흔들림, 섬광 감소. 조준점은 유효·사거리 밖·차단을 색과 모양으로 구분한다. 위험 예고도 색에만 의존하지 않는다. 음향·이펙트는 게임 이벤트를 구독하며 물리 시간을 멈추지 않는다.
