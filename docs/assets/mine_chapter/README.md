# 광산 6~10스테이지 에셋

동굴보다 어둡고 산업적인 광산 분위기로 제작했다. 전용 세로 배경5개, 철재 지형9종, 승강기·광차·이동링·재충전링·압착기·톱·4방향 가시·경고등16종을 제공한다. 실제 이미지 수와 추출 좌표는 atlas.json을 따른다. 원본 PNG는 수정하지 않았다.

STAGES_06_10.md에 상승·하강·재상승 경로, 가시 사망 규칙, 난이도 상승, 체크포인트, 공정한 실패·카메라·검증 기준을 정리했다. IMPLEMENTATION_PROMPT.md는 기존 게임 개발자에게 전달할 적용 프롬프트이며 IMAGE_PROMPTS.md는 실제 이미지 제작 프롬프트다.

stages_patch.json은 기존 20개 목록에서 mine_01~05만 갱신하는 데이터다. artAvailable=true, available=false로 제공해 아직 없는 맵을 실행하지 않도록 했다. 게임 맵 구현·검증이 끝난 항목만 available=true로 변경한다. 이름·기록·잠금 상태는 기존 스테이지 선택 창을 재사용한다.

배경은 충돌 없는 비반복 원경이다. 모든 배경이 세로형이어도 실제 플레이 화면은 16:9로 유지한다. 배경 철골·가시·레일을 게임 오브젝트로 자동인식하지 않는다. 지형은 모듈 조각이며 경계가 완전히 맞는 자동타일은 아니다. 장치의 콜라이더·고정점 중심·피스톤 이동·발판 상단은 엔진에서 지정해야 한다.

검사 범위는 PNG·알파·비중첩 추출 좌표·데이터 참조다. 실제 맵·충돌·클리어 가능성은 검증하지 않았다. validation.json에 검사 범위를 기록했다.
