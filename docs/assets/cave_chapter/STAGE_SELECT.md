# 스테이지 선택 창 적용 명세

## 구성

절제된 청회색 바탕, 얇은 테두리, 선택 시만 낮은 채도의 청록 강조를 사용한다. 본문은 밝은 회색, 기록은 중간 회색, 잠금은 어둡게 하되 읽을 수 있게 한다. 큰 광원·금색 장식·반복 반짝임은 사용하지 않는다.

1280×720 기준: 바깥 안전 여백 64px, 상단 제목과 닫기, 그 아래 동굴/광산/지하도시/지상 탭, 왼쪽 스크롤 스테이지 목록, 오른쪽 선택 스테이지 미리보기와 목표·기록, 하단 시작·뒤로. ui_layout.json은 이 구조의 기준값이다. 작은 창에서는 목록과 상세를 세로로 쌓고 목록을 스크롤한다. 게임 플레이 시야와 메뉴 레이아웃은 별도로 관리한다.

## 데이터 확장

stages.json에는 20개 본편의 ID·챕터·이름·선행 ID·available이 있다. 이 묶음에서 실제 배경과 아트가 제공된 범위는 동굴 1~5다. 광산 이후는 available=false이므로 저장에서 unlocked가 되어도 아직 실행하지 않는다. 신규 맵·리소스를 추가하고 available=true로 바꾸면 같은 카드를 재사용한다. 저장 키는 배열 인덱스가 아닌 고정 ID다.

상태는 잠금(이전 스테이지 미완료), 시작 가능, 선택, 클리어로 분리한다. 키보드 포커스는 선택 여부와도 별도로 표현한다. 클리어 표식·최고시간·최소사망·선택수집품·노체크포인트 기록은 런타임 텍스트와 아이콘으로 합성한다. 기록이 없으면 `—`로 표시하고 0초로 표시하지 않는다. 잠금된 카드를 선택해 목표와 해금 조건을 확인할 수 있지만 시작 버튼은 비활성이다.

## 입력과 경계

방향키/W·S로 목록 포커스 이동, Enter로 선택 또는 시작, Esc로 닫기. Tab은 탭·목록·상세·버튼을 순회한다. 마우스로 카드를 누르면 같은 selectedStageId를 갱신한다. UI가 열려 있는 동안 게임의 총·갈고리 입력은 소비한다. 클릭한 프레임에 게임 조작까지 통과시키지 않는다. 모달을 닫으면 이전 게임 상태로 돌아간다.

## 이미지 사용

assets/sheets/stage_select_ui_kit.png는 일반/선택/잠금 카드, 일반/선택/비활성 버튼, 창 패널, 자물쇠와 체크 아이콘을 포함한다. 실제 추출 좌표는 atlas.json을 쓴다. 이미지에 텍스트가 없으므로 한국어 이름·현지화·추가 기록을 자유롭게 표시한다. 기본 판은 캔버스와 native UI의 기본 패널로도 대체할 수 있다. 9-slice 모서리는 잘린 이미지의 실측 테두리 두께를 보고 설정한다. 생성 이미지에 약한 광원 표현이 있으므로 선택 판을 기본보다 낮은 알파로 겹치고 과한 빛은 추가하지 않는다.

## 로컬 참고 화면

압축 해제 후 preview.html을 브라우저에서 열면 다섯 배경 썸네일·챕터 탭·선택·잠금·시작 가능 상태를 확인할 수 있다. 처음에는 프롤로그 완료·동굴1만 해금된 예시 상태다. 콘솔에서 `stagePreview.complete('cave_01')`처럼 완료 상태를 바꿔 해금 전환을 살펴볼 수 있다. 이 예시 저장은 메모리에만 있고 실제 게임 저장 파일을 읽거나 수정하지 않는다. 시작은 `stage-launch-request` 이벤트를 내보내며 실제 맵 로더는 연결되지 않았다. 참고 화면은 엔진에 옮겨야 하는 UI 구조와 상태 흐름을 보여 주는 도구다.
