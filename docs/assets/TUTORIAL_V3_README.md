# HOOK & RECOIL 튜토리얼 에셋 V3

## 구성
배경 PNG 1개, 이동 시트 16포즈, 액션 시트 16포즈, 지형 조각 12개, 타일 9개, 기능 소품 16개. 모든 그림은 새로 생성한 원본 PNG다. 이미지 자체를 재샘플링하거나 다시 그리지 않았다.

## 추출
atlas.json의 rect는 원본 PNG에서 추출할 x,y,width,height다. 등분 자동 자르기 대신 이 좌표를 사용한다. 프레임 간 좌표 겹침이 없음을 검사했고 외곽에 3px 여유를 포함했다. PNG의 투명 알파를 보존한다. 검은색이나 붉은색을 색상 키로 제거하면 얼굴과 머플러도 지워지므로 사용하지 않는다.

## 렌더링
Nearest 필터, 정수 배율, 정수 화면 좌표를 사용한다. 배경은 한 장의 비반복 이미지다. 로프는 hook·rope 소품으로 별도 렌더링한다. 총·발사기는 별도 장착 부품을 조준 방향으로 회전시킨다. 충돌 판정은 그림의 알파나 모자·머플러 외곽에서 자동 생성하지 않고 플레이어 컨트롤러에서 독립 관리한다.

## 동작
이동 시트: idle, run, air(준비/상승/정점/낙하), land. 액션 시트: grapple, swing, recoil, death. air 4개는 반복 재생하는 루프가 아니라 수직 속도와 접지 상태에 따라 선택하는 포즈다. fps는 시작 설정이며 물리 시간과 애니메이션 시간은 분리한다.

## 검증 범위와 남은 작업
투명 알파, 각 시트의 주요 그림 개수, 추출 사각형의 비중첩을 검사했다. 실제 엔진은 제공되지 않아 엔진 내 임포트·피벗 정렬·루프 재생·장착부 접합·반복 타일 연결·충돌 검증은 수행하지 않았다. 따라서 이 묶음을 무수정 적용이 보장된 최종 리소스로 표시하지 않는다. 프레임별 기준점과 부품 결합 좌표는 아직 확정하지 않았다. 타일은 생성된 9분할 원본이며 픽셀 단위 무이음 연결은 보장되지 않는다. 명세서 20개 스테이지 전체의 장치·HUD·음향을 포함하는 전체 게임 에셋 세트는 아니다.
