# 지하도시 V2 적용 상태

작성: 2026-10-30. [V2 아트/레벨 설계](assets/city_chapter/v2/REDESIGN_AND_LEVELS.md)를 기존 Java/libGDX 런타임에 통합한 범위와 검증 결과를 기록한다. 원본 V1 문서와 이미지는 보존하고 V1 도시 아트는 런타임에서 로드하지 않는다.

## 적용 내용

- [v2_atlas.json](../assets/city_chapter/v2_atlas.json)의 명시 rect로 V2 시트를 로드한다. V2 PNG와 설계 자료는 `assets/city_chapter/assets_v2/`, `docs/assets/city_chapter/v2/`에 보존한다.
- 각 도시 스테이지에 새 가로 배경과 기존 세로 배경을 비반복 원경으로 등록했다. `CityBackgroundSelector`는 카메라 구역 히스테리시스와 0.35초 크로스페이드를 적용한다. 16:9 화면비와 게임플레이 충돌은 변경하지 않는다.
- V2 맵은 6/7/8/9/10 모듈 데이터, 얇은 보행판, one-way/solid·ropeStops 구분, 열린 비충돌 프레임, 이동판, 링·바람·장벽·톱·압착기·붕괴판 데이터를 사용한다. 얇은 판은 충돌체 높이 H 기준 0.16H로 시작한다. 그림 비율을 유지하고 투명 픽셀로 콜라이더를 만들지 않는다.
- 생성기에는 실제 이동거리 목표 100/125/150/180/210H를 기록하지만 `lengthMeasured=false`다. 이 목표를 완성 맵의 실측값이나 난도 상승 검증으로 간주하지 않는다.
- 고정 ID `city_01`~`city_05`와 진행/보석/체크포인트 동작을 유지한다. 사용자의 테스트 요청에 따라 다섯 스테이지를 선택·실행 가능 상태로 둔다.

## 실행한 검증

- `:core:verifyCity`: 데이터·충돌·장치 assertion 295개 통과. 스크립트 입력 경로는 `city_01`~`city_04`에서 clear gem에 도달했다. `city_05`는 경로 중 이동 장치 충돌로 사망해 clear gem에 도달하지 못했다. 이 자동 경로는 수동 플레이테스트가 아니다.
- `:lwjgl3:verifyCityNative`: 24개 확인 통과. V2 atlas, 10개 배경 변형, 다섯 스테이지 로드, 16:9 오프닝 카메라 및 시간 정지를 확인했다. 전체 구간 플레이테스트는 수행하지 않았다.
- `:core:verifyPrologue`: 134 assertion 통과. `:core:verifyCaves`: 79 assertion 통과(30/60/144 FPS 경로 검사 포함).
- 생성된 JSON 10개를 UTF-8로 파싱했고 `git diff --check`를 실행했다.

## 남은 검증

- 실제 조작으로 `city_01`~`city_05` 전체 경로, 체크포인트 재시작, 장치와 줄의 상호작용을 플레이테스트해야 한다. 특히 `city_05`의 자동 경로가 이동 장치에 사망하는 원인을 실제 게임에서 확인하고 구간 또는 통과 타이밍을 조정해야 한다.
- 100/125/150/180/210H 목표와 핵심 연계 수는 아직 실측·플레이 검증하지 않았다. 11→15 난도 상승, 최대속도 관통, 배경 전환 이음새, 플랫폼 정렬도 실제 카메라에서 확인되지 않았다.
- V2 전극 PNG에는 아크가 포함되어 있어 비활성 상태에서 중립 영역만 그린다. 수납 가시의 모든 전환 상태와 크러셔 주기의 실제 애니메이션은 별도 플레이 확인이 필요하다.
