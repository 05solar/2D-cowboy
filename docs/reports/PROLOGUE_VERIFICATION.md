# 프롤로그 검증 기록

## 크기·총·스윙 조정 후 재검증

`core:verifyPrologue`: **130개 assertion 통과**. 캐릭터·충돌체 75%, 회전 총 알파 45%, 접선 가속 20H/s², 줄 당김 2.4H/s(목표 길이 3.7H)를 적용한 결과다.

총을 전혀 발사하지 않고 두 링을 사용하는 경로에서 두 번째 링 해제 위치를 x=34.1 / 34.5 / 34.9로 달리했을 때 각각 x=38.108 / 39.433 / 40.628에 착지했다. 모두 반대편 발판 x=36~41 안이다. 반동을 추가한 기존 경로도 살아서 착지한다(x=46.431). 기본 점프/반동 점프 거리, 100회 복원, 공중 무연결, 충돌, FPS 일관성 검증도 유지된다.

아래 121개 검증과 초기 경로의 수치는 조정 전 이력이다. 실제 사용자 마우스 조작에 의한 완주 테스트와 자동 입력 검증은 구분한다.

날짜: 2026-10-26. 환경: Windows 11 amd64, Eclipse Adoptium Java 21.0.12.1, Gradle 9.7.1. 선언 libGDX 1.14.2. 기준 성능 PC 사양 확정이나 전체 게임 출시 검증은 아니다.

## 자동 물리 검증

`gradlew.bat core:verifyPrologue`: **121개 assertion 통과**. 별도 그래픽 모의 구현이 아니라 실제 `StageRuntime`, `PlayerController`, `CollisionWorld`, `GrappleSystem`, `RecoilSystem`과 배포 JSON을 사용했다.

`gradlew.bat build`: 종료 코드 0. 전체 빌드와 배포 JAR 생성 성공. Java 8 소스/타깃의 향후 지원 중단 관련 컴파일 경고는 있으나 컴파일 오류는 없다.

| 항목 | 실제 결과 |
|---|---|
| 기본 점프, x=15.5에서 시작 | 같은 높이로 돌아올 때 x=18.500. 반대편 x=21에 닿지 못함 |
| 동일 시작에서 점프+0.1초 뒤 뒤/아래 1발 | x=23.144에서 반대편 발판에 착지 |
| 기본 점프 대비 도달 거리 | 약 3.0H 대 7.644H, 반동 점프가 더 멂 |
| 천장 구간 | 첫 링·두 번째 링 연결 및 반동 조합 후 x=38.270에 착지 |
| 첫 2H 구멍 | 기본 점프로 착지 |
| 마지막 4H 구멍 | 반동 점프로 착지하고 출구 완료 판정 |
| 천장 없는 곳 | 위로 발사해도 연결되지 않음 |
| 잘못된 맵 | 천장 없는 링을 데이터 검증에서 거부 |
| 고속 충돌 | 긴 이동을 한 번에 요청해도 바닥·측벽을 관통하지 않음 |
| 천장 차단 | 천장을 지나는 선분은 차단됨 |
| 줄 해제 | 기존 vx/vy 보존 |
| 탄약·간격 | 바닥 유지 중 무한 충전 없음, 0.22초 내 연속 발사 차단 |
| 체크포인트 | 100회 복원에도 위치·속도 0·2발·줄 없음 일치 |
| 프레임 독립성 | 30/60/144FPS 스케줄에서 240개의 동일 틱 입력을 실행, 위치 오차 0.0001H 미만 |

초기 천장 구간 검증에서는 너무 낮은 위치에서 마지막 반동을 써 착지하지 못했다. 첫 줄 해제 시 아래쪽 반동으로 높이를 확보하고 두 번째 링에 재연결하는 경로로 검증했으며, 안내 문구에도 이 순서를 반영했다. 스윙만으로 자동 통과하는 맵으로 바꾸지 않았다.

## 화면·임포트 검증

데스크톱 JAR을 실제 실행해 PNG 로드·atlas rect·한국어 글꼴·화면 렌더링 후 30프레임에서 캡처하고 정상 종료했다. [시작 화면](prologue-start.png), [천장 구간](prologue-ceiling.png)을 시각 확인했다.

천장 구조물이 HUD에 가려졌던 부분은 카메라 높이를 수정했다. 한국어 글꼴의 처음 메트릭/얇은 획 문제는 실제 글리프 경계와 Bold/선형 필터로 수정했다. 플레이어 발판 접점, 투명 배경, 반전용 프레임 복사본, 전경과 배경 분리를 확인했다.

## 범위와 남은 검증

- 자동 경로 검증과 렌더 스모크 검증이며, 사람이 마우스로 모든 구간을 완주한 플레이테스트를 주장하지 않는다.
- 지속 FPS·메모리·다른 PC·모든 리사이즈 조합·키보드 포커스 이벤트의 장시간 수동 검증은 미실행이다.
- 사용자 에셋은 원본 그대로 사용했다. 프레임별 정밀 피벗, 시트에 그려진 총과 별도 회전 총의 완벽한 결합, 타일 무이음은 후속 조정 대상이다.
- 저장·음향·위험물 전체·정식 20개 맵은 이 프롤로그 검증 범위가 아니다.
- `core:test`는 JUnit 테스트 검색을 사용하지 않고 `verifyPrologue` 실행에 의존하도록 설정했다. 테스트 없음 실패만 끄고 검증을 생략한 것이 아니다. assertion 실패는 Gradle 작업을 실패시킨다.
