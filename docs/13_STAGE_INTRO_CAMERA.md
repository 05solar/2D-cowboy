# 스테이지 시작 카메라 안내 연출

일반 플레이에서 스테이지를 새로 불러오면 카메라가 플레이어 스폰 지점에서 출발한다. 약 1.8초 동안 클리어 보석 위치까지 부드럽게 이동하고, 보석을 0.4초 보여 준 뒤 약 1.5초에 걸쳐 플레이어에게 돌아온다. 수직 스테이지에서도 기존 16:9 뷰포트와 월드 카메라 경계를 유지한다.

연출 중에는 플레이어·장치의 물리와 스테이지 시간이 진행되지 않으며, 이동·발사·갈고리 입력을 비운다. 연출 도중 일시정지하면 카메라 시계도 멈춘다. 조작을 시작할 때 held 입력이 이어지지 않도록 입력 상태를 초기화한다. 메뉴에서 새 스테이지를 고르면 해당 스테이지의 소개 연출을 새로 시작한다. 저장된 진행 복원과 획득 연출 복원에는 재생하지 않는다.

시간과 보간은 `StageIntroCamera`가 관리하고 `GameplayScreen`이 스테이지 로드, 입력 차단, 물리 정지, 실제 카메라 반영을 담당한다. 미리보기 스크린샷 모드는 연출을 건너뛰어 기존 화면 캡처 동작을 유지한다.
