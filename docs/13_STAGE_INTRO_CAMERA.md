# 스테이지 시작 카메라 안내 연출

일반 플레이에서 스테이지를 새로 불러오면 카메라는 다음 순서로 움직인다.

1. 주인공 스폰을 일반 플레이 배율로 보여준다.
2. 화면을 축소하면서 맵 중앙으로 이동해 스테이지 전체가 한 화면에 들어오도록 보여준다. 전체 맵 프레임에 약 8% 여백을 둔다.
3. 전체 맵을 잠시 보여준 뒤 보석 위치로 이동하면서 일반 배율로 확대한다.
4. 보석을 잠시 비추고 주인공 스폰으로 돌아와 일반 플레이를 시작한다.

이동과 줌은 부드럽게 보간한다. 기본 16:9 뷰포트는 유지하고, 카메라의 보이는 크기에 맞춰 월드 경계를 제한한다. 한 장짜리 배경은 반복하지 않으며 기존 카메라 구역 전환과 크로스페이드를 유지한다.

안내 연출 중에는 플레이어·장치 물리와 스테이지 시간이 진행되지 않고, 입력을 소비한다. 일시정지하면 카메라 연출도 멈춘다. `StageIntroCamera`는 줌·카메라 위치 단계와 연출 시간 상태를 소유하고, 스테이지를 다시 불러올 때 모든 상태를 초기화한다. `GameplayScreen`은 스테이지 로드·입력 차단·물리 정지·실제 카메라 반영을 담당한다. 스크린샷 미리보기 모드는 안내 연출을 건너뛴다.

## 확인

`:core:compileJava`, `:lwjgl3:compileJava`, `:core:verifyPrologue`, `:lwjgl3:verifyCityNative`로 컴파일과 시작 카메라를 확인한다. 네이티브 검증은 연속 스테이지 로드, 전체 맵이 화면에 들어오는지, 보석 위치 확대, 스폰 복귀, 카메라 이동·줌의 프레임 간 변화, 안내 중 시뮬레이션 정지를 검사한다. 입력에 의한 전체 스테이지 플레이테스트를 대신하지 않는다.
