# HOOK & RECOIL 개발 문서

광산 챕터 6~10 통합과 미완료 검증은 [광산 챕터 적용 상태](MINE_CHAPTER_STATUS.md)를 참고한다.

작성일: 2026-10-26. 현재 단계: V3 에셋을 사용한 테스트 프롤로그 구현. 정식 20개 스테이지는 개발 계획 단계다.

실행·조작·실제 구현 범위는 [테스트 프롤로그](10_PROLOGUE.md)를 먼저 확인한다.

최신 변경: [클리어 보석·2초 획득 연출·완료 저장](11_GEM_CLEAR.md). 출구 도달 조건을 보석 접촉으로 대체했다.

UI 폰트는 둥근모꼴+ Fixedsys를 사용하며 원본 글꼴과 라이선스는 `assets/ui/fonts/`에 포함했다.

동굴 본편 1~5 통합·실제 입력 경로·스테이지 선택과 검증 기록: [동굴 챕터](12_CAVE_CHAPTER.md).

## 문서 적용 기준

- 사용자 지시를 우선한다. 원본은 게임 기획의 기준이며 바이트 변경 없이 보관한다.
- 후속 문서는 원본을 구현하기 위한 설계다. 원본에 없는 선택은 `설계안`, 아직 검증되지 않은 값은 `초기값/목표`, 결정이 필요한 항목은 `미정`으로 표시한다.
- 게임 규칙을 바꿀 때는 변경 이유·영향·검증 결과를 결정 기록에 남기고 관련 문서를 함께 수정한다. 원본을 조용히 덮어쓰지 않는다.
- 기능별 상세 구현 파일과 테스트 파일은 해당 단계에서 만든다. 아래 구조에 나오는 예정 파일이 이미 구현되었다고 간주하지 않는다.
- 소스 작업 전 [루트 AGENTS.md](../AGENTS.md)와 코드 작성 규칙을 읽는다.
# 광산 챕터 6~10

광산 에셋과 엔진 통합 상태는 [광산 적용 문서](assets/mine_chapter/README.md), 설계 청사진은 [STAGES_06_10.md](assets/mine_chapter/STAGES_06_10.md)를 참고한다. 구현된 스테이지 1~10은 테스트를 위해 모두 선택 가능하다. 자동 검증 명령은 `:core:verifyMines`와 `:lwjgl3:verifyMinesNative`다. 전체 완주 경로는 아직 검증 중이다.
