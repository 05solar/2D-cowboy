# 보석 획득 에셋 보관

사용자가 제공한 `gem_pickup_set_v1` 원본을 복사했다. `APPLY.md`는 적용 원문, `atlas.json`은 캐릭터 rect·피벗·소켓·포즈 시간과 효과 실측 경계, `validation.json`은 제공 당시 검증 범위다.

`assets/player_collect.png`: 8포즈 원본 시트. `assets/gem.png`: 보석. `assets/aura.png`: 후광. `assets/pulse_ring.png`: 확산 링. `assets/sparkle.png`: 섬광. 원본 이미지와 투명 여백을 보존한다.

실제 게임 적용 결과는 [구현 문서](../../docs/11_GEM_CLEAR.md)에 별도로 기록한다. 원본 validation의 `engine_tested: false`를 수정하지 않는다.
