# 동굴 1~5스테이지 에셋 묶음

프롤로그 이후 본편 동굴 1~5를 대상으로 한다. 원 명세의 순서·과제·체크포인트 수를 유지하고 최근 결정인 보석 획득 완료 조건을 적용한다.

| ID | 이름 | 주요 에셋·과제 | 중간 체크포인트 |
|---|---|---|---:|
| cave_01 | 깨어난 굴 | 넓은 동굴 배경, 안전 발판·고정 링, 연결→해제→반동 | 2 |
| cave_02 | 메아리 협곡 | 깊은 협곡 배경, 높이가 다른 링·복구 발판, 연결 전환 | 2 |
| cave_03 | 가시 틈새 | 낮은 통로 배경, 4방향 가시·좁은 착지, 궤도·제동 | 2 |
| cave_04 | 부서지는 발판 | 붕괴 지층 배경, 발판 intact/warning/collapse/gone | 2 |
| cave_05 | 수직 균열 | 세로 균열 배경, 링·붕괴 발판·가시 종합 | 1 |

assets/backgrounds에 각 스테이지 전용 PNG 5개, assets/sheets에 공통 지형·기능 장치·UI 구성 요소 PNG 3개가 있다. 기존 주인공·보석·획득 세트는 재사용하며 이 묶음에 중복 복사하지 않았다. 별도 오디오·실제 맵 좌표·자동타일 리소스는 포함하지 않는다.

IMAGE_PROMPTS.md는 실제 이미지 생성 프롬프트, IMPLEMENTATION_PROMPT.md는 기존 게임 개발 에이전트에 전달할 적용 프롬프트다. STAGE_SELECT.md와 ui_layout.json은 선택 창 확장 규칙, stages.json은 20개 데이터 골격이다. preview.html은 오프라인 선택 창 참고 화면이다.

atlas.json은 실제 그림의 추출 좌표다. PNG는 원본을 보존한다. 부드러운 후광을 그림 외곽으로 판단해 과도하게 자르지 말고, 자동 등분 대신 좌표를 사용한다. 붕괴 파편은 여러 연결 요소로 나뉘지만 하나의 프레임으로 추출한다. 연결 링에는 짧은 로프가 포함돼 기존 줄 렌더러와 중복될 수 있다.

공통 지형은 재사용 가능한 덩어리 형태다. 맞닿는 경계가 픽셀 단위로 검증된 무이음 자동타일 세트는 아니다. 지형 콜라이더와 아트를 분리하고 실제 엔진에서 크기·정렬·이음새를 확인해야 한다. 배경의 돌출부는 모두 장식이며 충돌이나 링 판정이 없다.

validation.json의 검사는 파일·알파·추출영역·참조·선택 상태 모델에 한정한다. 5개 플레이 가능한 맵 제작이나 해당 맵의 클리어 가능성, 엔진 내부 UI 적용이 완료됐다는 뜻은 아니다.
