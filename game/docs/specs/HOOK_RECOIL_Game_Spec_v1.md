# HOOK & RECOIL — 2D 액션 등반 게임 기본 명세서

버전: 1.0 · 작성일: 2026-10-21 · 상태: 구현 전 기획 초안

이 문서의 물리 수치, 구간 길이, 클리어 시간은 초기 설계값이다. 실제 구현·플레이테스트를 거쳐 확정하며, 명시된 시간은 검증된 플레이타임이 아니다.

## 1. 게임 개요

| 항목 | 명세 |
|---|---|
| 가제 | HOOK & RECOIL / 훅 앤 리코일 |
| 장르 | 스테이지형 2D 고난도 액션 플랫포머 |
| 시점 | 측면, 상하좌우 스크롤, 상승 중심 |
| 기본 플랫폼 | PC, 키보드·마우스, 싱글 플레이, 오프라인 |
| 구성 | 동굴 → 광산 → 지하도시 → 지상, 테마별 5개, 총 20개 스테이지 |
| 핵심 행동 | 갈고리로 진자 운동 → 줄 해제 → 발사 반동으로 궤도 보정 → 재연결·착지 |
| 성공 조건 | 스테이지 출구 구역에 살아 있는 상태로 진입 |
| 실패 조건 | 가시·분쇄기 등 치명적 위험물 접촉 또는 맵 바깥 추락 |
| 성장 구조 | 능력치 강화 없이 플레이어의 숙련도와 스테이지 해금으로 진행 |
| 게임의 약속 | 조작에 익숙해질수록 같은 장애물을 더 정확하고 빠르게 통과할 수 있다. |

깊은 지하에서 깨어난 정비공이 갈고리 장치와 반동 추진 총을 사용해 지상으로 탈출한다. 스토리는 시작·테마 전환·엔딩의 짧은 장면과 배경으로 전달한다. 전투·경험치·장비 파밍은 기본 범위에서 제외한다.

## 2. 완성도와 난이도 원칙

1. 어렵게 만드는 대상은 타이밍, 조준, 속도, 자원 사용 순서다. 작은 글씨·불분명한 충돌·시야 밖 함정으로 난이도를 만들지 않는다.
2. 새 장치는 안전한 관찰 구간 → 단독 과제 → 기존 장치와 결합 순서로 소개한다.
3. 실패 직후 원인을 이해하고 같은 조건에서 다시 도전할 수 있어야 한다.
4. 주요 정답 경로는 갈고리와 반동 모두를 사용한다. 고급 기술로 일부를 단축하는 것은 허용하되, 무한 추진으로 전체를 건너뛰는 것은 방지한다.
5. 테마의 마지막 스테이지는 해당 테마 기술의 종합 시험이다. 처음 보는 장치를 마지막 시험에 넣지 않는다.
6. 일반 진행에는 제한 시간을 두지 않는다. 빠른 클리어·노데스·수집은 선택 도전이다.

## 3. 기본 플레이 흐름

타이틀 → 이어하기/새 게임/스테이지 선택 → 시작 안전지대 → 구간 관찰 → 이동·갈고리·반동으로 돌파 → 체크포인트 → 출구 → 결과 → 다음 스테이지.

스테이지 안에서는 실패 횟수에 제한이 없다. 다음 스테이지는 현재 스테이지를 클리어하면 열린다. 클리어한 스테이지는 언제든 다시 도전할 수 있다. 중도 종료 후 이어하기는 마지막 활성 체크포인트에서 시작한다.

## 4. 조작 체계

| 입력 | 동작 | 세부 규칙 |
|---|---|---|
| A / D | 좌우 이동 | 공중에서는 제한적인 속도 보정만 가능 |
| Space | 점프 | 바닥에서 1회, 이단 점프·벽 점프 없음 |
| 마우스 이동 | 조준 | 총과 갈고리 모두 커서 방향 사용 |
| 마우스 왼쪽 클릭 | 반동 발사 | 클릭당 1발, 누르고 있어도 자동 발사하지 않음 |
| 마우스 오른쪽 누르기 | 갈고리 발사·유지 | 누를 때 1회 발사, 유효 고정점 적중 후 누르는 동안 유지 |
| 마우스 오른쪽 떼기 | 줄 해제 | 해제 순간의 속도 유지 |
| R | 마지막 체크포인트 재시작 | 즉시 실행, 메뉴에서 스테이지 처음부터 재시작 별도 제공 |
| Esc | 일시정지 | 재개·설정·스테이지 선택·타이틀 |

입력은 설정에서 변경 가능하다. 갈고리 유지 방식은 기본 ‘누르기’, 선택 ‘토글’을 제공한다. 스크롤 줄 길이 조절은 기본 버전에서 제외해 조작을 줄인다. 설명은 긴 팝업보다 시작 안전지대의 짧은 입력 안내와 시범 구조로 전달한다.

## 5. 플레이어와 물리 규칙

### 5.1 기준 단위와 초기 튜닝

플레이어 충돌체 높이를 H=1로 두고 맵 치수와 속도를 표현한다. 그림 크기와 충돌체는 분리하며, 충돌체는 그림보다 약간 작게 설정한다.

| 항목 | 초기 설정 | 조정 목적 |
|---|---|---|
| 물리 갱신 | 고정 120Hz, 렌더링과 분리 | 30·60·144FPS에서 일관된 궤도 |
| 중력 | 24H/s² | 짧고 선명한 포물선 |
| 점프 초기 속도 | 위쪽 8H/s | 단독 점프 높이 약 1.33H |
| 지상 최고 속도 | 4.5H/s | 안전지대 내 기본 이동 |
| 공중 수평 가속 | 5H/s² | 실패 복구 가능, 추진 기술 대체 방지 |
| 공중 입력 속도 범위 | 수평 속도 ±4.5H/s 안에서만 가속 | 이미 얻은 빠른 속도를 자동으로 낮추지 않음 |
| 전체 속도 상한 | 16H/s | 충돌 안정성·과도한 가속 방지 |
| 점프 코요테 타임 | 0.08초 | 발판 끝의 불필요한 입력 실패 완화 |
| 점프 입력 버퍼 | 0.10초 | 착지 직전 입력 수용 |
| 유효 착지 판정 | 위를 향하는 바닥 접촉이 0.05초 유지 | 벽 접촉·모서리 스침을 재충전으로 오인하지 않음 |

수치는 하나의 출발점이다. 특히 점프 높이, 갈고리 길이, 반동량을 함께 검증하고 한쪽만 크게 바꾸지 않는다. 속도 상한은 일반 경로에서 반복적으로 걸리지 않게 조정한다.

### 5.2 갈고리

- 기본 연결 대상은 명확한 링 모양 고정점이다. 일반 벽에는 연결되지 않는다. 고정점은 모양·외곽선으로도 식별 가능해야 한다.
- 기본 최대 사거리 7H, 갈고리 발사체 속도 40H/s. 유효 대상까지 시야가 뚫려 있어야 하며 벽을 관통하지 않는다.
- 마우스로 지정한 방향에서 고정점에 맞으면 연결한다. 적중 보정은 고정점 시각 범위 안의 작은 허용 영역으로만 제공한다.
- 줄 길이는 연결 순간의 거리로 고정하며, 길이보다 가까운 위치에서는 줄이 느슨해질 수 있다. 길이를 넘으려 할 때 장력이 발생하는 최대 거리 제약으로 구현한다.
- 장력이 걸린 동안 플레이어는 진자 운동한다. 좌우 입력으로 제한적으로 흔들림을 키울 수 있다.
- 줄을 놓으면 접선 방향 속도가 유지된다. 연결만으로 자동으로 끌어올리거나 정지시키지 않는다.
- 한 번에 연결 1개. 재연결하려면 기존 줄 해제 후 다시 발사한다. 발사 간 최소 간격은 0.15초다.
- 비행 중인 갈고리 또는 연결 줄이 고형 지형에 막히면 실패·해제된다. 줄이 지형 모서리를 감싸는 기능은 제외하며, 막히기 직전 줄 색·음향으로 상태를 알려준다.
- 갈고리 자체에는 사용 횟수 제한이 없다. 사용 기회는 고정점 위치·사거리·시야·환경으로 제한한다.
- 고정점을 잡은 상태에서 반동 발사가 가능하다. 반동은 접선 방향 추진과 흔들림 보정에 쓰이며 줄 방향 바깥쪽 속도는 제약에 따라 제거된다.

### 5.3 반동 추진 총

- 총은 전투용이 아닌 이동 도구다. 조준 방향의 반대로 플레이어 속도에 순간 변화량을 더한다.
- 초기 반동량은 5.5H/s, 발사 간격 0.22초, 최대 장전 수 2발이다.
- 아래쪽 발사 → 상승, 오른쪽 발사 → 왼쪽 이동, 진행 방향 발사 → 감속, 대각선 발사 → 궤도 보정.
- 발사체는 시각·타격 피드백용이며 적이나 파괴 가능한 지형은 기본 범위에 넣지 않는다.
- 지상 유효 착지 시 2발로 즉시 재충전한다. 공중 재충전 링 통과 시에도 2발로 채우되 최대치를 넘지 않는다.
- 벽 접촉·고정점 연결·줄 유지·줄 해제만으로 탄약이 회복되지 않는다.
- 탄약 0발에서는 반동이 발생하지 않으며 빈 총 소리와 HUD 반응을 제공한다.
- 한 공중 재충전 링은 해당 시도에서 1회만 사용 가능하다. 사망·체크포인트 재시작 때 초기화한다.
- 총을 쏠수록 자동으로 높아지는 구조를 피한다. 정답 경로는 2발의 사용 위치와 중간 재충전·착지를 요구한다.

### 5.4 대표 기술

| 기술 | 입력·상황 | 사용 목적 |
|---|---|---|
| 스윙 점프 | 갈고리로 흔들다가 상승 접선 방향에서 해제 | 먼 간격 통과 |
| 반동 도약 | 발밑으로 발사 | 높은 고정점 사거리 진입 |
| 접선 가속 | 줄에 매달린 상태에서 이동 반대 방향으로 발사 | 스윙 속도 확보 |
| 공중 제동 | 진행 방향으로 발사 | 작은 발판에 착지 |
| 재연결 | 줄 해제 후 다음 고정점에 발사 | 연속 공중 이동 |
| 스윙→추진→연결 | 속도 확보, 해제, 반동 상승, 다음 링 적중 | 중후반 핵심 연속 동작 |

1스테이지부터 모든 기본 능력을 사용할 수 있다. 능력을 뒤늦게 잠금 해제하는 대신 맵으로 필요한 기술을 단계적으로 가르친다.

## 6. 실패·체크포인트·게임 모드

### 6.1 기본 모드

HP는 없으며 치명적 위험물 접촉 시 즉시 실패한다. 높은 곳에서 안전한 바닥으로 떨어지는 것은 피해가 없다. 일반 벽 충돌만으로 죽지 않는다. 벽에 부딪힐 때 접촉면 바깥 속도만 제거하고 가능한 이동은 유지한다.

사망 연출은 0.25초 이내, 입력 가능한 재시작은 사망 후 0.7초 이내를 목표로 한다. 재시작 시 플레이어 위치·속도·탄약·줄·재충전 링·함정·이동 장치를 체크포인트 기준 상태로 초기화한다. 사망 직전 유지한 클릭은 재발사로 이어지지 않고, 버튼을 놓은 뒤 새 입력을 받아야 한다.

| 스테이지 | 중간 체크포인트 수 | 권장 구성 |
|---|---|---|
| 1~4 | 각 2개 | 기술 학습을 짧게 반복 |
| 5 | 1개 | 동굴 종합 시험 |
| 6~9 | 각 2개 | 이동 장치 학습·조합 |
| 10 | 1개 | 광산 종합 시험 |
| 11~14 | 각 2개 | 정밀 구간과 복구 판단 |
| 15 | 1개 | 도시 종합 시험 |
| 16~19 | 각 2개 | 바람·지상 장치 학습·조합 |
| 20 | 2개 | 3개의 긴 최종 구간, 구간별 연속 성공 요구 |

모든 스테이지 시작점은 별도 기본 체크포인트다. 체크포인트는 위험이 없는 착지 공간에 배치하며 도달 즉시 저장한다. 후반부의 어려움은 저장 지점을 무작정 없애기보다 두 저장 지점 사이의 연속 동작에서 만든다.

### 6.2 선택 도전

- 기본 모드: 시간 제한·목숨 제한 없음. 최초 클리어와 다음 스테이지 해금의 기준.
- 노체크포인트 도전: 해당 스테이지 클리어 후 선택, 실패하면 스테이지 처음부터. 별도 완주 표식.
- 기록 도전: 같은 물리·맵·함정 조건으로 최단 시간 갱신. 일반 모드 기록과 구분.
- 연습 도구: 클리어한 구간을 체크포인트별로 선택해 연습. 여기서 달성한 기록은 정식 완주 기록에 넣지 않음.

느린 게임 속도·반동량 조정 같은 보조 설정은 출시 후 확장 항목이다. 도입할 경우 사용 여부를 기록에 표시하고 기본 기록과 분리한다.

## 7. 난이도 곡선과 설계 예산

성공적인 한 번의 주행 시간을 ‘순수 주행’으로 정의한다. 첫 클리어까지의 실제 소요시간은 실패 횟수에 따라 크게 달라진다.

| 테마 | 핵심 학습 | 순수 주행 목표/스테이지 | 체크포인트 사이 연속 동작 수 | 일반 목표 발판 폭 |
|---|---|---|---|---|
| 동굴 | 스윙·해제·반동·제동 | 45~90초 | 2~5회 | 2~3H |
| 광산 | 이동 대상·시간 제약 | 60~120초 | 4~7회 | 1.5~2H |
| 지하도시 | 좁은 통로·궤도 제어 | 90~150초 | 6~9회 | 1~1.5H |
| 지상 | 바람·종합 연계 | 90~180초 | 7~12회 | 0.8~1.2H |

연속 동작 1회는 의미 있는 연결·해제·발사·착지를 뜻한다. 단순 이동 입력은 세지 않는다. 위 시간은 대기나 연출로 늘리지 않는다. 좁은 발판은 진입 속도를 줄일 수 있는 공간과 함께 사용한다.

주요 위험은 같은 체크포인트에서 항상 같은 순서와 위상으로 시작한다. 랜덤 위치·랜덤 반동·갑작스러운 조준 흔들림은 없다. 기본 모드의 진행 구간에 0.15초 미만의 단발 타이밍 창을 요구하지 않는 것을 초기 가이드로 삼는다. 최적 기록용 지름길은 더 어렵게 설계할 수 있다.

## 8. 전체 20개 스테이지

각 스테이지는 아래 핵심 과제를 기준으로 최소 3개 구간을 구성한다. 체크포인트 1개인 시험 스테이지는 앞·뒤 두 덩어리로 묶되 내부에 짧은 안전 발판을 둘 수 있다. 정답은 하나의 입력값이 아니라 허용 궤도 범위로 설계한다.

### 8.1 동굴: 1~5스테이지

시각: 짙은 청회색 바위, 물방울, 청록 발광 광물. 플레이 경로는 배경보다 밝고 선명하게 구분한다.

| 번호·이름 | 구성과 필수 과제 | 난이도·실패 구조 |
|---|---|---|
| 1. 깨어난 굴 | 안전 바닥에서 이동·점프·반동 조작 → 넓은 구덩이 위 고정점 스윙 → 줄 해제와 1발 추진을 결합해야 닿는 출구 | 초반 실패는 아래 안전 발판으로 복구. 마지막 구간부터 낙사 도입. 목표 발판 폭 3H |
| 2. 메아리 협곡 | 높이가 다른 고정점 2개를 순서대로 연결 → 스윙 정점 전후 해제 비교 → 사거리 밖 링에 반동으로 접근 | 늦은 해제는 벽에 막히고 이른 해제는 아래 안전 턱으로 하강. 후반은 같은 구조 아래 가시 배치 |
| 3. 가시 틈새 | 위·아래 가시 사이 스윙 → 반동으로 상승량 조정 → 진행 방향 발사로 제동 후 좁은 발판 착지 | 무조건 높은 점프가 정답이 아님을 학습. 천장과 출구가 접근 전에 보임 |
| 4. 부서지는 발판 | 착지 후 약 1초에 무너지는 발판 소개 → 착지 재충전 → 빠른 재출발과 다음 고정점 연결 | 발판 균열·소리로 붕괴 예고. 안전한 도입 발판 뒤 연속 붕괴 구간. 시간은 튜닝 대상 |
| 5. 수직 균열 | 스윙→추진→재연결 → 붕괴 발판에서 재충전 → 가시 통로 제동 착지를 두 구간에 배치 | 동굴 종합 시험. 신규 장치 없음. 마지막 4~5개 동작을 연속 성공해야 출구 도달 |

### 8.2 광산: 6~10스테이지

시각: 철재 지지대, 황색 작업등, 레일, 리프트. 이동 장치의 경로와 작동 방향을 레일·표지로 보여준다.

| 번호·이름 | 구성과 필수 과제 | 난이도·실패 구조 |
|---|---|---|
| 6. 채굴 승강로 | 일정 경로를 왕복하는 승강기와 이동 고정점 소개 → 반동으로 높이 맞추기 → 이동 고정점에서 다음 링으로 전환 | 관찰용 안전 턱 제공. 이동 고정점은 무제한 상승하지 않고 정해진 범위만 왕복 |
| 7. 광차 교차로 | 광차를 착지·재충전 발판으로 사용 → 차체 고정점 스윙 → 다른 레일로 횡단 | 광차의 진행 방향과 주기 고정. 광차 위 착지는 정상 착지로 인정. 벽에 끼이는 구조는 치명 구역으로 표시 |
| 8. 분쇄 설비 | 주기적으로 닫히는 압착기 소개 → 스윙 가속으로 개방 중 통과 → 반동 제동으로 다음 대기 턱 착지 | 작동 전 경광등·소리, 열린 틈 너머 안전지대 사전 노출. 대기 공간 없는 무작위 압착 금지 |
| 9. 과열 운반로 | 8번에서 멀리 보였던 회전 톱을 주 장애물로 사용 → 이동 고정점 스윙 → 공중 재충전 링 첫 필수 사용 → 2발 분배 | 재충전 링은 안전한 도입 구간에서 먼저 설명. 속도만 높이면 톱에 충돌하므로 가속·제동 전환 필요 |
| 10. 폐광 탈출 | 승강기 탑승 → 압착기와 톱 구간 → 광차에서 재충전 → 연속 고정점으로 상부 출구 | 광산 종합 시험. 작동 순서는 고정. 체크포인트 뒤 6~7개 연속 동작 요구 |

### 8.3 지하도시: 11~15스테이지

시각: 폐역, 환기 시설, 낡은 주거지, 네온 표식. 배경 창문·전선은 충돌 대상과 다른 명도로 처리한다.

| 번호·이름 | 구성과 필수 과제 | 난이도·실패 구조 |
|---|---|---|
| 11. 폐역 진입 | 낮은 천장 아래 스윙 → 출구 앞 공중 제동 → 플랫폼 아래로 줄 해제 후 반대편 연결 | 좁은 공간의 속도 제어 학습. 갈고리 줄이 플랫폼에 막힐 수 있음을 안전 구간에서 시연 |
| 12. 환기 구역 | 일정 방향·세기의 환풍기 소개 → 기류를 이용해 링 사거리 진입 → 반동으로 횡풍 보정 | 바람 영역 경계와 입자로 방향·세기 표시. 스테이지 중 풍량은 임의 변경하지 않음 |
| 13. 단전 거리 | 켜짐·꺼짐을 반복하는 전기 장벽 관찰 → 안전 시간에 통과 → 공중 링을 지나 다음 통로로 연결 | 전기 장벽은 갈고리 줄·발사체도 차단. 꺼짐 직전 예고 점멸. 재연결 시점과 경로 선택 요구 |
| 14. 무너진 거주구 | 붕괴 발판 → 건물 모서리 앞 줄 해제 → 아래쪽 고정점 재연결 → 좁은 실내 착지 | 단순 상승 대신 하강 후 재상승. 낙하 경로가 카메라에 미리 보이고 안전 턱 위치 식별 가능 |
| 15. 중앙 환기탑 | 기류 상승 → 전기 장벽 통과 → 이동 고정점 → 좁은 착지·재충전 → 상부 출구 | 도시 종합 시험. 기본 경로에서도 갈고리와 반동을 여러 차례 교대. 체크포인트 뒤 8~9개 연속 동작 |

### 8.4 지상: 16~20스테이지

시각: 동틀 무렵 외곽 시설에서 시작해 옥상·송신탑·해 뜨는 정상으로 전개. 밝은 하늘에서도 고정점과 캐릭터 윤곽이 유지되어야 한다.

| 번호·이름 | 구성과 필수 과제 | 난이도·실패 구조 |
|---|---|---|
| 16. 첫 하늘 | 실외 횡풍을 안전 발판에서 확인 → 넓은 건물 간격 스윙 → 역풍에서 반동 상승·착지 | 도시 환기 기류를 넓은 공간으로 확장. 구역별 고정 풍향 사용. 뒷배경 구름을 고정점처럼 보이지 않게 처리 |
| 17. 옥상 사이 | 건물 사이 고정점 연속 전환 → 재충전 링 1개를 경유 → 마지막 1발을 제동에 남겨 작은 옥상 착지 | 초반에 탄약을 다 쓰면 마지막 착지가 어려움. 실패 전 중간 안전 턱에서 다시 계획할 기회 제공 |
| 18. 송신탑 | 왕복 정비 리프트 → 좁은 철골 통로 → 횡풍 속 고정점 전환 → 붕괴 발판 출발 | 광산 이동 장치와 도시 정밀 조작 결합. 속도가 높을수록 줄이 철골에 막힐 위험 증가 |
| 19. 구름 경계 | 예고 후 켜지는 시설 전기 장벽 → 방향이 다른 고정 기류 구역 → 재충전 링 통과 후 긴 공중 연계 | 새 랜덤 날씨를 추가하지 않음. 안전 턱에서 경로 관찰 가능하나 출발 후 9~10개 동작을 연속 수행 |
| 20. 마지막 상승 | 1구간: 낮은 천장·스윙 제동 / 2구간: 이동 고정점·장벽·재충전 / 3구간: 횡풍·긴 공중 연계·정상 착지 | 총 3구간, 구간 사이 체크포인트 2개. 마지막 구간은 10~12개 동작. 신규 장치·엔딩 직전 숨겨진 함정 없음 |

최종 출구는 넓고 안전하게 구성한다. 플레이어가 정상에 도착해 조작으로 마지막 몇 걸음을 이동한 뒤 엔딩을 시작한다.

## 9. 난이도를 공정하게 유지하는 맵 제작 규칙

- 플레이 공간은 타일 기반으로 제작하되, 고정점·함정·체크포인트는 별도 오브젝트로 배치한다.
- 스테이지마다 기본 정답 경로 1개, 선택 고난도 경로 최대 1개를 원칙으로 한다.
- 기본 경로는 시작·체크포인트의 정지 상태와 완전 장전 상태에서 반드시 통과할 수 있어야 한다. 이전 구간에서 가져온 특정 속도를 요구하지 않는다.
- 각 구간의 마지막 착지는 다음 구간을 관찰할 수 있는 공간을 제공한다. 붕괴 발판을 관찰 지점으로 사용하지 않는다.
- 출발 전에 다음 연결 대상 또는 명확한 중간 목표가 화면에 보여야 한다. 고속 이동 중 시야 밖 링에 즉시 조준하는 과제를 넣지 않는다.
- 함정 작동 전의 안전 상태·예고·위험 상태를 모양, 애니메이션, 소리로 구분한다.
- 함정은 프레임 수가 아닌 물리 시간 기준으로 갱신하며 체크포인트별 위상을 고정한다.
- 떨어진 위치에서 복구 가능하면 복구 경로를 둔다. 탄약도 고정점도 없고 이동도 불가능한 상태는 빠르게 낙사 처리하거나 R 안내를 표시한다.
- 고정점 간 거리는 사거리만으로 결정하지 않는다. 실제 속도·발사체 이동시간·탄약·장애물을 포함해 검증한다.
- 압착기·이동 발판은 플레이어가 지형 내부로 밀려 들어가지 않도록 충돌·끼임 처리를 갖춘다.
- 랜덤 맵·랜덤 함정은 기본 버전에서 제외한다. 반복 학습으로 실력이 향상되는 고정 스테이지를 우선한다.

## 10. 카메라·화면·피드백

### 10.1 카메라

기본 화면비는 16:9다. 울트라와이드에서는 기록 공정성을 위해 플레이 시야 범위를 동일하게 유지한다. 가변 창 크기에서도 HUD와 조준 좌표가 일치해야 한다.

카메라는 플레이어를 중심으로 이동 방향을 약간 선행 추적한다. 상승 시 상단, 하강 시 하단을 미리 보여주되 방향 전환 순간 급격히 흔들리지 않는다. 조준 대상이 화면 밖으로 밀려나지 않게 데드존과 선행량을 함께 조정한다. 자동 줌은 기본 버전에서 제외하며, 필요 구간은 일관된 사전 설정을 사용한다.

### 10.2 HUD·메뉴

| 화면 | 필수 요소 |
|---|---|
| 플레이 HUD | 테마·스테이지명, 탄약 2칸, 체크포인트 알림, 선택 표시 타이머·사망 수 |
| 조준점 | 유효 고정점/사거리 밖/차단 상태를 모양과 색으로 구분 |
| 결과 | 클리어 시간, 사망 수, 수집품, 개인 최고, 다음 스테이지·재도전 |
| 스테이지 선택 | 4개 테마, 20개 스테이지, 해금 상태, 최고 기록·완주 표식 |
| 설정 | 음량, 키 변경, 화면 모드, 화면 흔들림, 섬광 감소, 갈고리 입력 방식 |

### 10.3 조작 피드백

갈고리 적중은 짧은 금속음·연결 섬광, 해제는 줄 수축, 발사는 총구 섬광·반동 자세, 착지는 먼지·짧은 자세 변화로 표현한다. 탄약이 0·1·2발일 때 HUD를 즉시 갱신한다. 화면 흔들림은 약하게 제공하고 끌 수 있게 한다. 적중·발사 연출로 물리 시간을 멈추지 않는다.

위험물의 실제 충돌 범위는 보이는 위험 부분을 넘지 않는다. 장식용 체인·케이블·광물은 플레이용 고정점과 혼동되지 않게 한다. 어두운 테마에서도 어둠 자체를 난이도 수단으로 삼지 않는다.

## 11. 기록·수집·반복 플레이

각 스테이지에 선택 수집품 1개, 총 20개를 둔다. 수집품은 기본 경로보다 어려운 우회 경로에 배치하며 다음 스테이지 해금에는 필요하지 않다. 수집 후 사망하면 해당 수집을 취소하고, 체크포인트 또는 출구 도달 시 영구 저장한다. 영구 저장된 수집품은 재도전 중 표시만 바꾸고 재수집을 강제하지 않는다.

완주 표식은 기본 클리어, 수집품 확보, 노체크포인트 완주, 목표 시간 달성으로 나눈다. 목표 시간은 개발자 추정으로 확정하지 않고 실제 테스트 기록을 보고 정한다. 온라인 순위표·계정·멀티플레이·일일 미션은 초기 범위에서 제외한다.

일반 모드 클리어 시간은 사망·재시작 대기까지 포함한 해당 시도의 실제 플레이 경과 시간이다. 일시정지·앱 비활성 시간은 제외하고 물리·함정도 정지한다. 체크포인트 재시작으로 타이머와 사망 수를 초기화하지 않는다. 스테이지 처음부터 재시작은 새 시도로 기록한다. 노체크포인트 모드 기록은 별도 저장한다.

## 12. 저장 데이터

로컬 저장에 스키마 버전을 두고 임시 파일 작성 후 교체하는 방식으로 저장한다. 설정 변경·체크포인트 도달·수집 확정·스테이지 클리어 시 저장하고 마지막 정상 저장 백업을 유지한다.

|---|---|
| 진행 | 최고 해금 스테이지, 각 스테이지 클리어 여부 |
| 이어하기 | 스테이지 ID, 체크포인트 ID, 모드, 경과 시간, 시도 사망 수 |
| 수집 | 영구 확보 수집품 ID |
| 기록 | 모드별 최고 시간, 최소 사망 수, 노체크포인트 완주 여부 |
| 설정 | 입력 매핑, 음량, 화면, 연출 설정 |
| 버전 | 저장 스키마 버전, 물리·맵 규칙 버전 |

이어하기는 체크포인트에서 재개하므로 탄약·속도·함정 상태를 체크포인트 기준으로 복원한다. 실행 도중의 임의 공중 위치를 그대로 저장하지 않는다. 맵 또는 물리가 기록에 영향을 줄 정도로 변경되면 이전 기록의 버전을 보존해 구분한다.

## 13. 구현 구조와 맵 데이터

엔진은 미정이다. 기본 명세는 엔진과 무관하며 실제 프로젝트의 언어·엔진을 확정한 뒤 구현 상세를 작성한다. 물리 엔진의 거리 제약·연속 충돌 지원 여부를 먼저 확인한다.

| 구성 | 책임 |
|---|---|
| PlayerController | 입력 버퍼, 지상·공중 이동, 점프 |
| GrappleSystem | 발사·적중·사거리·줄 제약·차단·해제 |
| RecoilSystem | 반동 충격량, 발사 간격, 탄약·재충전 |
| HazardSystem | 가시·압착·톱·전기 장벽·사망 판정 |
| StageRuntime | 맵 로드, 출구, 체크포인트 상태와 장치 초기화 |
| MovingPlatform / Anchor | 정해진 경로 이동, 탑승 속도 전달, 이동 고정점 |
| WindZone | 영역별 고정 방향·가속 적용 |
| CameraController | 경계, 선행 추적, 조준 좌표 변환 |
| RunTracker / SaveService | 시간·사망·모드·수집·기록·안전한 저장 |
| UI / Audio | HUD·메뉴·설정·상태 피드백 |

스테이지 데이터에는 ID, 테마, 맵 경계, 시작점, 출구, 체크포인트, 충돌 지형, 고정점, 이동 경로·주기·초기 위상, 함정과 위험 범위, 기류, 재충전 링, 수집품, 카메라 구간 설정을 포함한다. 모든 상호작용 오브젝트는 고유 ID를 가져야 한다.

게임 상태는 타이틀·플레이·일시정지·사망·재시작·클리어·엔딩으로 분리한다. 사망과 출구가 같은 물리 틱에 발생하면 사망을 우선한다. 재시작 중에는 이동·발사 입력을 받지 않는다.

고속 이동 충돌은 스윕 또는 연속 충돌 검출로 처리한다. 줄 제약을 적용한 위치 보정도 지형 관통을 만들지 않아야 한다. 이동 고정점은 고정점의 이동 속도를 반영해 줄 제약을 풀고, 이동 발판 이탈 시 발판 속도 전달을 한 번만 적용한다.

## 14. 필수 에셋 범위

- 플레이어 1종: 대기·달리기·점프·낙하·매달림·발사·착지·사망. 상체·총은 조준 방향을 반영한다.
- 플레이 기능: 고정 링, 이동 링, 재충전 링, 출구, 체크포인트, 수집품, 줄·갈고리·발사 효과.
- 공통 위험물: 가시, 붕괴 발판, 압착기, 회전 톱, 전기 장벽, 기류 표시.
- 테마별 타일·배경 4세트: 바닥·벽·모서리·일방통행 발판·원경·전경 장식. 장식 레이어는 플레이 가독성을 해치지 않는다.
- UI: 타이틀, 테마·스테이지 선택, HUD, 결과, 설정, 짧은 조작 안내.
- 소리: 발사·빈 탄약·갈고리 발사/적중/해제·착지·사망·체크포인트·재충전·함정 예고·클리어. 테마별 배경음 4종과 환경음.

픽셀 아트와 일반 2D 중 화풍은 별도 결정한다. 화풍 확정 전에는 단색 도형으로 물리·스테이지를 검증한다.

## 15. 제작 순서와 완료 기준

| 단계 | 작업 범위 | 다음 단계 진입 기준 |
|---|---|---|
| 1. 조작 실험 | 빈 테스트맵, 점프·스윙·반동·재연결·충돌 | 갈고리와 반동을 섞는 것이 단독 사용보다 재미있고, 같은 입력의 결과가 일관됨 |
| 2. 대표 스테이지 | 동굴 1·3·5의 초안, 죽음·재시작·카메라 | 학습·정밀 조작·종합 시험이 각각 성립하고 반복 도전이 빠름 |
| 3. 공통 시스템 | 메뉴·저장·맵 데이터·체크포인트·기록 | 진행 유실 없이 스테이지를 전환하고 재개 가능 |
| 4. 동굴 완성 | 1~5 전체, 테마 에셋·음향 | 설명 없이도 기본 규칙을 학습하고 5번에서 숙련을 요구함 |
| 5. 테마 확장 | 광산 → 도시 → 지상 순서 | 각 테마 장치를 검증한 뒤 5개를 구성, 20개 전체 연속 진행 가능 |
| 6. 완성도 | 수집·도전 모드·설정·연출·밸런스 | 아래 출시 후보 검증 통과 |

20개 맵을 먼저 만든 뒤 물리를 바꾸면 전체 맵을 다시 조정해야 한다. 1~3단계에서 이동의 기준을 안정시킨 뒤 확장한다. 게임 완성도는 스테이지 수보다 입력·충돌·카메라·재시작의 품질을 우선한다.

## 16. 플레이테스트와 출시 후보 검증

### 16.1 난이도 검증

초기에는 신규 플레이어와 액션 게임 경험자를 함께 관찰한다. 특정 인원수의 작은 표본을 전체 사용자 통계처럼 해석하지 않는다.

- 1번에서 점프·갈고리·반동의 역할을 이해하는지 확인한다. 초반 목표는 반복 실패 후 이해할 수 있는 것이며, 설명만 읽고 수행할 것을 기대하지 않는다.
- 5·10·15·20번의 클리어는 이전 테마의 중간 스테이지보다 더 많은 시도를 요구하도록 조정한다.
- 사망 원인을 조준 실패·해제 시점·과속·탄약 계획·함정 위상·시야 문제·충돌 오류로 나눠 기록한다.
- 같은 위치에서 반복 실패할 때 사용자가 다음 시도를 바꾸는지 확인한다. 원인을 설명하지 못하면 안내·시야·충돌부터 수정한다.
- 구간별 시도 수·완주 시간의 중앙값과 범위를 보고 조정한다. ‘어려울수록 좋다’는 이유만으로 실패 횟수 목표를 고정하지 않는다.
- 핵심 루트에서 갈고리·반동 중 하나가 계속 생략되면 고정점·천장·간격·재충전 위치를 재설계한다.
- 마지막 3개 스테이지는 숙련 플레이어도 여러 번 연습해야 하지만, 성공 입력이 과도하게 한 픽셀·한 프레임에 묶이지 않아야 한다.

### 16.2 필수 검증 목록

| 분야 | 합격 기준 |
|---|---|
| 물리 | 같은 고정 입력을 30·60·144FPS 렌더 환경에서 실행했을 때 같은 경로·생존 결과, 주요 도착 위치 오차 0.05H 이내 목표 |
| 충돌 | 최대 속도에서 얇은 벽·바닥·함정 관통 없음, 줄 보정으로 벽 통과 없음 |
| 자원 | 벽 스침·갈고리 반복으로 무한 충전 불가, 링 1회 사용·사망 초기화 일치 |
| 리셋 | 체크포인트 100회 반복 재시작에도 장치 위상·탄약·속도·줄·링 상태 일관 |
| 맵 | 20개 모두 체크포인트 정지 상태에서 출구까지 검증, 필수 고정점 누락·진행 불가 상태 없음 |
| 이동체 | 이동 고정점·광차 위에서 연결·이탈·발사해도 속도 중복 가산·끼임 관통 없음 |
| 저장 | 체크포인트·클리어·수집·설정 저장과 재실행 복원, 손상 저장 시 백업 복구 |
| 입력 | 키 변경·버튼 유지·창 포커스 상실·일시정지 복귀 시 원치 않는 발사 없음 |
| 화면 | 창 크기 변경에도 조준 일치, 배경과 위험물 구분, 고속 이동 목적지 시야 확보 |
| 반복 플레이 | 사망 후 0.7초 내 조작 가능 목표, 결과·메뉴로 재도전 방해 없음 |

성능 목표는 기준 PC 사양을 정한 뒤 1080p 60FPS 이상으로 검증한다. 아직 기준 하드웨어와 실제 측정값은 없다. 엔진·출시 플랫폼·권장 사양은 후속 기술 명세에서 확정한다.

## 17. 기본 범위 확정

필수: 20개 고정 스테이지, 갈고리·반동 복합 이동, 4개 테마, 체크포인트, 빠른 재시작, 로컬 저장, 스테이지 선택, 기본 기록, 선택 수집품, 입력·음량·연출 설정, 시작·엔딩.

후순위: 노체크포인트 모드, 구간 연습 선택, 목표 시간 표식. 일반 모드의 20개 전체를 검증한 뒤 추가한다.

제외: 일반 적·보스 전투, 능력치 강화, 절차 생성 맵, 계정·서버·온라인 순위표, 멀티플레이, 상점, 장비 제작, 모바일 조작. 이후 확장은 핵심 조작을 안정시킨 다음 판단한다.

**최종 지향점:** 갈고리로 만든 속도를 반동으로 다듬고, 다음 고정점과 착지까지 계획해야 하는 게임. 실패는 짧고 반복 학습은 분명하며, 마지막 스테이지의 성공은 플레이어가 조작을 숙달했다는 증거가 되어야 한다.
